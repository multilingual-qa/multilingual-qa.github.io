    Ask in Bangla, answer in Bangla

    Questions come from real native-speaker queries about everyday life, across 18 topics such as food and drinks, travel, religion, tradition, education, names and weather. Your system answers each one in the language it was asked.

    Subtask 2A

    Monolingual QA

    One model per language. Each model only ever sees its own language.

    Multilingual QA

    One model trained on all four languages, including low-resource Assamese, answers every question.

    One submission file

    All your tracks go into a single task.jsonl. Every track you include must answer all test questions of that language.

    2A model rule

    One model per language. Different 2A languages may use different models.

    2B model rule

    One multilingual model, trained on all four languages, for every 2B language you submit, even if you submit only some.

    Rankings

    Eight per-track leaderboards ranked by BERTScore F1, plus 2B All-Languages for teams covering all four languages in 2B.

    Any pre-trained model or publicly available data may be used and must be described in your system paper. The MultiNativQA test split is our dev-test set and must not be used for training.

      Get the files

      Clone the repository and build the data files. They are written per language and combined, in JSON Lines format.

      git clone https://github.com/AridHasan/blp27_task2.git
cd blp27_task2
pip install -r requirements.txt
python data/prepare_data.py

      One line per question

      Each record has an id, language, region, topic, question and reference answer. The blind test set has no answers.

      {"id": "en_qa_cf92ec1e…",
 "lang": "en", "region": "qa",
 "category": "immigration",
 "question": "Can I extend my tourist visa in Qatar?",
 "answer": "If you would like to extend your visa, …"}

      How to submit

      Submissions are made on EvalAI. Use one EvalAI team for all of your team's runs; your latest submission for each track counts in the evaluation phase.

      1. Register your team

        Sign up on EvalAI, create a participant team and join the challenge.

        Open the challenge on EvalAI

      2. Build your system

        Start from the mT5 baseline or the LoRA fine-tuning script in the repository. Both write a ready-to-submit file.

        Browse the repository

      3. Check the file

        Run the format checker with the phase's question file. It confirms every track you submitted is complete.

      4. Upload task.jsonl

        Upload the file, or a zip containing it, on the Submit tab of the current phase.

      Submission format

      One JSON object per line. If you enter 2A and 2B for the same language, each question appears twice, once per subtask.

      {"id": "bn_bd_0a1b2c…", "subtask": "2A", "lang": "bn",
 "answer": "ঢাকার বিখ্যাত খাবারের মধ্যে কাচ্চি বিরিয়ানি অন্যতম।",
 "model": "banglat5-ft"}
      • subtask is 2A or 2B; lang is bn, en, as or hi.
      • 2A uses one model name per language; 2B uses one model name for all its rows.

      Check before uploading

      python format_checker/task.py \
  -p task.jsonl \
  --test-file data/test/all.jsonl

      The checker lists the tracks it found, for example:

      Tracks found -> 2A (Monolingual QA): Assamese;
2B (Multilingual QA): English, Assamese

      Ranked by BERTScore F1, with a native encoder per language

      Greedy cosine matching of contextual embeddings from layer 9, with no IDF weighting or rescaling. Inputs are truncated to 512 tokens and Bangla text is normalised before scoring.

      System papers

      Teams that submit during the evaluation phase and appear on a leaderboard are invited to describe their system in a short paper.

      Title format

      <Team Name> at BLP-2027 Task 2: <Descriptive title>

      AlphaX at BLP-2027 Task 2: Culturally-Aware LLM Fine-tuning for Multilingual Question Answering

      Length

      Up to four pages of content, plus references.

      Template

      The official ACL two-column templates, unmodified. Open on Overleaf

      Format check

      Run your PDF through the ACL pubcheck tool; non-conforming papers are rejected without review.
